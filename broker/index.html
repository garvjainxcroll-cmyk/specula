This page only appears when Netlify published the files without building them. The market needs its small server (a Netlify Function) so that every player shares the same prices.

  1. In Netlify, open this project → Deploys. Make sure you are signed in and drag the zip onto the Deploys page again (signed-in drops are built).
  2. If this page still appears, use the GitHub way in DEPLOY.md: it always builds the server.
  3. Check by opening /api/health on your site. It must say "ok":true.
